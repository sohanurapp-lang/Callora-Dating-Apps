# Callora - Premium Video Dating App

Callora is a modern, high-performance video calling and dating application built with React, Firebase, and Tailwind CSS. It features a robust coin-based economy, real-time signaling for video calls, and a sleek, intuitive user interface inspired by WhatsApp.

## Features

- **Real-time Video Calls:** High-quality video and audio communication using WebRTC.
- **Coin Economy:** Users can deposit coins and spend them to call hosts. Hosts earn coins for their time.
- **WhatsApp-Style UI:** Familiar and easy-to-use interface with smooth animations and glassmorphism.
- **Role-Based Access:** Distinct experiences for Users, Hosts, and Admins.
- **Secure Backend:** Powered by Firebase Authentication and Firestore with strict security rules.
- **Automated Deployment:** GitHub Actions workflow for seamless deployment to GitHub Pages.

## Tech Stack

- **Frontend:** React, Vite, Tailwind CSS, Framer Motion, Lucide React.
- **Backend:** Firebase (Auth, Firestore).
- **Deployment:** GitHub Actions, GitHub Pages.
